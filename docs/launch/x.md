**Tweet 1 (Hook & Value):**
GitHub deletes your repository traffic data after 14 days.

If you launch a product, get featured, or release a major update, that referral and view data is gone in two weeks.

We built GitHub Traffic Analytics to fix this:
https://github-traffic-analytics.ali-ammari.workers.dev

Here is how it works 🧵👇

**Tweet 2 (Public Analyzer):**
1/ Zero-login public growth engine.

Paste any public repo (e.g. `facebook/react` or `vercel/next.js`) to see:

- 7-day and 30-day star velocity
- Momentum scores
- Temporal release impact (14 days before vs 14 days after)

No account or OAuth needed.

**Tweet 3 (Private Traffic Retention):**
2/ 14-day limit bypassed.

Connect your repositories via GitHub OAuth or the GitHub App. Automated daily Edge Cron Workers snapshot views and clones into Cloudflare D1.

Compare multi-month traffic history or export anytime to CSV/JSON.
